# DS1ParameterRandomizer
A parameter randomizer for Dark Souls: Remastered that stays true to the base game. It randomizes:
- **Rings:** effects by rarity, with the text rewritten.
- **Spells:** payloads, looks, speed and homing, chained effects, and costs.
- **Projectiles:** arrows, throwables, enemy projectiles and traps.
- **Enemy behaviour:** turning, detection, pursuit, movement, poise and stamina.
- **Weapons:** rarity, scaling that matches damage, movesets and effects.
- **Armor:** generated by rarity, with effects.
- **Body and face:** NPC faces and bodies, and the character creation templates and physiques.

Every feature has its own tab, distribution and options. Presets are shareable as a short string.

It runs on top of the item, enemy and fog gate randomizers: everything they changed is kept.

## Using the release
1. Download `ds1rand-<version>-win64.zip` and unzip it anywhere.
2. If you use the other randomizers, run them first, in this order: item → enemy → fog gate.
3. Start `ds1rand.exe`.
4. Pick the game folder, a preset (Easy / Standard / Hard / Misery or your own), and optionally a seed. Then press **Randomize**.
5. By default the output goes to `out/randomized/` next to `ds1rand.exe`. Copy its `param` and `msg` folders over the game's, including the `.ds1rand-base` / `.ds1rand.json` files next to them. Alternatively, choose "Write into the game folder".
6. `ds1rand-spoiler.txt` in the output lists everything that changed.

Re-running is safe. ds1rand always rebuilds from the files as the other mods left them, so it never randomizes its own output again.

**Other features**
- **Validate install:** shows what other mods changed.
- **Audit tab:** browse how every param row is used and what a run changed.

**Command line**
`ds1rand-cli.exe --preset Standard --seed 1`. See `ds1rand-cli.exe --help` for feature switches, share strings and writing into the game folder.

Play offline: modified params are not safe online.

## From source
Requires Python 3.13+ and [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```

```bash
uv run python -m ds1rand.ui
```

```bash
uv run python tools/randomize.py --preset Standard --seed 1
```

Tests (need a DSR install; set `DS1R_GAME_DIR` if it is not in the default Steam folder):

```bash
uv run pytest -q
```

Building the release (PyInstaller; writes `dist/ds1rand/` and `dist/ds1rand-<version>-win64.zip`, then smoke-tests it):

```bash
uv run --group build python tools/build_release.py
```

## Layout
- `ds1rand/`: the package.
  - `io/`: game files.
  - `baseline/`: the vanilla snapshot and diffs.
  - `graph/`: the reference graph.
  - `catalogue/`: usage, subtypes, budgets, effect residency and inspection.
  - `alloc/`: row allocation and writing.
  - `features/`: the randomizers.
  - `presets/`, `ui/`, `cli.py`, `spoiler.py`.
- `data/baseline/`, `data/catalogue/`: the vanilla baseline and reference catalogue shipped with the app.
- `ds1paramdefs/`: community paramdefs, Meta and row names.
- `tools/`: maintenance scripts (baseline, graph, reports, install diffs, boot tests, release build).
- `packaging/`: the PyInstaller spec and entry points.
- `docs/`:
  - [ROADMAP](docs/ROADMAP.md): phases and design.
  - [AUDIT](docs/AUDIT.md): catalogue audit and in-game checks.
  - [MOD_COMPAT](docs/MOD_COMPAT.md): running on top of other mods.
- `legacy/`: the original prototype, kept for reference.
